# Sound pulse traveling down an air duct: a transient acoustic FEA study

This study drives one end of a 1 m air duct, 100 × 100 mm in section, with a Gaussian pressure pulse
and follows the sound wave to the far end, which is anechoic. The pulse, 1 Pa at its peak and
0.25 ms wide, comes from a MATLAB-language function, `gaussianPulse.m`, that the study imports. It
records the pressure at both ends every 0.1 ms for 6 ms. The pulse peak should reach the far end
L / c = 2.92 ms after it leaves, at 3.92 ms, with its 1 Pa height and 0.25 ms width unchanged.

## The problem

A transient acoustic analysis follows a sound wave in time, which a frequency sweep cannot show
directly: arrival times, reflections, and how a pulse changes shape as it travels. A plane pulse in
a straight duct with a non-reflecting end is the simplest check of that. The pulse should arrive
after the travel time L / c and keep its shape, because air has no dispersion and the duct has no
damping.

Here L = 1.000 m and c = 343 m/s for air at 20 °C, so the crossing takes 2.92 ms. The drive is
uniform over the end face, so it launches a plane wave. The duct's first cross mode is at

$$f_{1} = \frac{c}{2\,w} = \frac{343}{2 \times 0.1} = 1715\ \text{Hz}$$

and a uniform drive does not excite it, so the pulse stays plane.

## How the study works

1. **The pulse function.** `gaussianPulse.m` returns a Gaussian in time, and the study imports it:

   ```matlab
   z = (time - center) ./ width;
   pressure = peak .* exp(-0.5 .* z .* z);
   ```

   ```
   import function gaussianPulse from "./gaussianPulse.m"
   ```

2. **Geometry and mesh.** `geometry/duct-1000x100.step` holds the air as body `Air`, with faces
   `Driven end`, `Open end` and `Walls`. Quadratic tetrahedra at 25 mm, under the 28.6 mm that six
   elements per wavelength at 2 kHz would allow.

3. **The drive signal.** The study samples the function at 100 kHz from 0 to 6 ms to make the
   pressure signal on the driven end:

   ```
   signal pulse : pressure over time {
       generated by function.gaussianPulse {
           arguments {
               peak = 1 Pa
               center = 1 ms
               width = 0.25 ms
           }
           sample from 0 s to 6 ms at 100 kHz
   ```

4. **Boundaries.** Rigid walls, and a radiation condition on the far end that lets the plane wave
   leave without reflecting:

   ```
   load walls { acoustic.rigid_wall { target = geometry.duct.region.walls } }
   load anechoic_end { acoustic.radiation { target = geometry.duct.region.open_end } }
   ```

5. **Study.** An acoustic transient from 0 to 6 ms in 0.02 ms steps, about twelve per pulse width,
   with the pressure at (0, 0, 0) and (1000, 0, 0) mm sampled every 0.1 ms.

## Results

| Quantity | Hand check |
| --- | --- |
| Travel time, L / c | 2.92 ms |
| Peak at the driven end | 1 Pa at 1.0 ms |
| Peak at the far end | 1 Pa at 3.92 ms, between the 3.9 and 4.0 ms samples |
| Duct's first cross mode | 1715 Hz, not driven |

The study returns `driven_end_history`, `far_end_history` and the final pressure field. Plot the two
histories together: the far-end pulse should be the driven-end pulse shifted by 2.92 ms, and by
6 ms the far-end pressure should have fallen back to zero, since the anechoic end sends nothing
back.

## What to try

1. Change `width` to 0.5 ms. The pulse is twice as long in time, and the arrival time stays
   2.92 ms after the peak leaves.
2. Change `speed_of_sound` to 500 m/s, roughly hot exhaust gas. The crossing takes 2.00 ms, so the
   far-end peak moves to 3.00 ms.
3. Replace the radiation condition on the open end with a rigid wall. The pulse reflects there
   without inversion, so the far-end history peaks at 2 Pa at 3.92 ms, and the field shows the
   reflected pulse heading back up the duct.
