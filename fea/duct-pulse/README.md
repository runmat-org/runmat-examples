# Sound pulse in a duct

A pressure pulse traveling down an air duct with an anechoic end. Card example for **transient**
acoustics on `/simulation/acoustics`.

## Setup

| Item | Value |
| --- | --- |
| Geometry | `geometry/duct-1000x100.step`: `Air`, 1000 mm (x) × 100 × 100 mm. Faces `Driven end` (x = 0), `Open end` (x = 1000 mm), `Walls` |
| Air | 20 °C: 1.204 kg/m³, 343 m/s |
| Drive | Pressure on `Driven end`: a Gaussian pulse, 1 Pa peak at 1 ms, 0.25 ms standard deviation, generated by `gaussianPulse.m` and sampled at 100 kHz |
| Boundaries | `Walls` rigid; `Open end` radiating (anechoic for the plane wave) |
| Mesh | Quadratic tetrahedra, 25 mm (six per wavelength at 2 kHz is 28.6 mm) |
| Analysis | `acoustic transient`, 0 to 6 ms in 0.02 ms steps |

The drive is uniform over the end face, so it launches a plane wave; the duct's first cross mode
(c / (2 × 0.1 m) = 1715 Hz) is not driven.

## Outputs

- `driven_end_history`, `far_end_history`: pressure at the corner nodes (0, 0, 0) and
  (1000, 0, 0) mm every 0.1 ms from 0.1 to 6 ms.
- `pressure`: final pressure field.

## Hand check

The pulse crosses the duct in L / c = 1.000 / 343 = **2.92 ms**. Its peak leaves the driven end at
1.0 ms and reaches the far end at **3.92 ms** (between the 3.9 and 4.0 ms samples), still 1 Pa
high and 0.25 ms wide, since the anechoic end does not reflect it. By 6 ms the far-end pressure
has fallen back to zero.
